Omarchy：这个 Linux，有点不太一样

2026-08-29
阅读时长: 1 分钟
字数: 152字

如果你已经看腻了 Windows，又觉得传统 Linux 桌面少了点意思，那么 Omarchy 值得你花一个晚上折腾一下。

最近体验了一个让我眼前一亮的 Linux 发行版——Omarchy。

它不是那种努力把自己伪装成 Windows 或 macOS 的 Linux。

恰恰相反。

它似乎在告诉你：

既然都用 Linux 了，为什么不彻底一点？

⚡ 第一眼：这很 Linux，但也很未来

Omarchy 是一个基于 Arch Linux 打造的现代 Linux 发行版，由 DHH 发起。

它很有自己的脾气。

平铺式窗口、键盘驱动的操作逻辑、终端、快捷键、主题，以及一整套已经搭配好的开发环境，让整个桌面看起来不像传统意义上的“电脑桌面”。

更像是一间属于开发者的数字驾驶舱。

打开窗口。

Super + ...

切换。

再开一个终端。

窗口自动重新排列。

用习惯之后，你甚至会开始嫌弃鼠标：

“这东西怎么还需要我伸手去拿？”

🧩 它真正有意思的地方，是“不让你从零开始”

Arch 很迷人。

但 Arch 的经典体验通常是：

安装系统 → 查 Wiki → 配桌面 → 配窗口管理器 → 配终端 → 配快捷键 → 配主题 → 配着配着天亮了。

Omarchy 的思路不太一样。

它直接给了你一套已经做过选择的答案。

从桌面环境、快捷键、终端工具，到常用应用和主题，它并不是单纯往 Arch 上塞一堆软件，而是在尝试构建一套完整、统一的工作方式。

这也是我觉得 Omarchy 最特别的地方：

它卖的不是“自由选择”，而是“有人替你认真选择过”。

对于喜欢折腾的人来说，你依然可以继续改。

但对于只想拥有一套漂亮、高效 Linux 工作环境的人来说——

终于不用先花三天研究 .config 了。

🖥️ 特别适合哪类人？

如果你是下面这类用户，我会非常推荐体验一次：

程序员 / Linux 爱好者 / 极客 / 键盘党 / 喜欢极简桌面的人。

尤其是平时经常在 Terminal、VS Code、Neovim、Git、SSH、Docker 之间来回切换的人。

Omarchy 那种“所有东西都在键盘触手可及的位置”的感觉，很容易让人上瘾。

当然，它并不一定适合所有人。

如果你的需求只是微信、Office、网页、看看视频，然后希望所有操作方式都和 Windows 一模一样，那么 Ubuntu、Linux Mint 之类的传统桌面发行版可能更加省心。

但如果你想体验：

“2026 年的 Linux 桌面还能怎么玩？”

Omarchy 很值得试试。

🚀 最后

我喜欢 Omarchy，并不是因为它比其他 Linux 发行版“更强”。

而是因为它有一种现在越来越少见的东西：

明确的审美，以及明确的主张。

它没有试图讨好所有人。

它只是把一种 Linux 工作方式做到足够漂亮，然后告诉你：

This is how we use computers.

至于你喜不喜欢？

装一次就知道了。
